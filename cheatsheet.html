Changer l'adresse, la passerelle, le DNS ou le nom

La commande NETCONFIG (« Net Config by VE2CUY ») fait tout ce qui suit : elle demande l'adresse, le masque, la passerelle et les serveurs DNS, valide les réponses, redémarre le réseau, puis teste la passerelle et le DNS par un ping. Elle demande la langue au lancement; NETCONFIG F la lance en français, NETCONFIG E en anglais. Elle est installée par le bouton « Installer TCP/IP » et se trouve sur le disque OpenVMS + TCP/IP du dépôt. À la main :

Modifiez CMUIP_ROOT:[SYSMGR]INTERNET.CONFIG avec EDIT/TPU CMUIP_ROOT:[SYSMGR]INTERNET.CONFIG (Ctrl+Z enregistre). C'est ce fichier que lit IPACP. N'écrivez pas plutôt dans SYS$MANAGER: : un nouveau fichier y irait dans SYS$SPECIFIC et IPACP ne le verrait pas.

! Adresse et masque (carte XQA0) :
Device_Init:XEDRV:XQA0:00-00-00-00-00-00:192.168.2.77:255.255.255.0

! Passerelle par défaut (réseau 0.0.0.0, masque 0.0.0.0) : une ligne par passerelle
Gateway:ROUTER:192.168.2.1:0.0.0.0:0.0.0.0

Pour les serveurs de noms (DNS), modifiez CMUIP_ROOT:[SYSMGR]NAMRES.CONFIG (essayé avec un routeur et 8.8.8.8) :

! Domain_Server:domaine:nom-du-serveur:adresse:port   (« . » : tous les domaines)
Domain_Server:.:DNS1:192.168.2.1:53
Domain_Server:.:DNS2:8.8.8.8:53

Pour le nom d'hôte, changez la ligne Define/System/Exec/NoLog INTERNET_HOST_NAME "VAXEMU.LOCAL" de CMUIP_ROOT:[SYSMGR]IP_STARTUP.COM.

Appliquer les changements sans redémarrer VMS (essayé dans l'émulateur) :

$ IPNCP NAMRES EXIT 1          ! arrêter d'abord le résolveur de noms (sinon il plante)
$ IPNCP NETEXIT                ! puis attendre le message « IPACP: Network offline » (≈ 10 s)
$ @SYS$MANAGER:IP_STARTUP      ! « IPACP: Net device 0 is XQA0:, IP=... (Online) »
$ IPNCP STARTUP /NAMRES        ! si NAMRES n'est pas reparti (SHOW SYSTEM)
$ IPNCP PING 192.168.2.1 64 3  ! vérifier la passerelle
$ IPNCP PING GOOGLE.COM 64 3   ! vérifier le DNS

Vous pouvez aussi redémarrer VMS (@SYS$SYSTEM:SHUTDOWN, redémarrage automatique YES). Pour tout reprendre, relancez @SYS$UPDATE:VMSINSTAL CMUIP depuis la trousse.

Dans l'émulateur, voici les adresses selon le mode réseau :
  • Réseau virtuel (menu Réseau) : VAX en 10.0.2.15, masque 255.255.255.0, passerelle 10.0.2.2.
  • Pont local (relais vax-bridge, ou term --bridge) : une adresse libre de votre réseau, par exemple 192.168.2.77, avec votre routeur comme passerelle.
Le PC qui fait le pont joint le VAX par telnet localhost 2323.

Dans l'émulateur

  • Disques du dépôt (OpenVMS 7.1 installé) : comptes SYSTEM, SYSTEST et FIELD, mot de passe VAX_EMU_2026.
  • Pour changer de disque, éteignez le VAX, sauf quand le bouton « Installer TCP/IP » change lui-même le CD.
  • Coller : bouton de la barre ou Ctrl+Maj+V. Copier : sélectionner le texte, puis le bouton Copier.
  • Turbo (barre du haut) : le VAX va aussi vite que le fureteur le permet quand il travaille (démarrage d'OpenVMS en 9 s environ) et garde le temps réel quand il attend; l'horloge de VMS prend un peu d'avance (SET TIME=12-OCT-2026:18:30 pour la remettre à l'heure).
  • Les disques sont gardés dans le fureteur, qui peut les effacer si l'espace manque : gardez-en une copie avec le bouton Télécharger du menu Disques. Arrêtez OpenVMS (@SYS$SYSTEM:SHUTDOWN) avant de fermer l'onglet.

Changing the address, gateway, DNS or name

The NETCONFIG command ("Net Config by VE2CUY") does all of the following: it asks for the address, mask, gateway and DNS servers, validates the answers, restarts the network, then tests the gateway and the DNS with a ping. It asks for the language when it starts; NETCONFIG E runs it in English, NETCONFIG F in French. It is installed by the Install TCP/IP button and is on the repository's OpenVMS + TCP/IP disk. By hand:

Edit CMUIP_ROOT:[SYSMGR]INTERNET.CONFIG with EDIT/TPU CMUIP_ROOT:[SYSMGR]INTERNET.CONFIG (Ctrl+Z saves). This is the file IPACP reads. Do not write to SYS$MANAGER: instead: a new file would go to SYS$SPECIFIC, which IPACP never sees.

! Address and mask (card XQA0):
Device_Init:XEDRV:XQA0:00-00-00-00-00-00:192.168.2.77:255.255.255.0

! Default gateway (network 0.0.0.0, mask 0.0.0.0): one line per gateway
Gateway:ROUTER:192.168.2.1:0.0.0.0:0.0.0.0

For name servers (DNS), edit CMUIP_ROOT:[SYSMGR]NAMRES.CONFIG (tried with a router and 8.8.8.8):

! Domain_Server:domain:server-name:address:port   ("." : every domain)
Domain_Server:.:DNS1:192.168.2.1:53
Domain_Server:.:DNS2:8.8.8.8:53

For the host name, change the line Define/System/Exec/NoLog INTERNET_HOST_NAME "VAXEMU.LOCAL" in CMUIP_ROOT:[SYSMGR]IP_STARTUP.COM.

Apply the changes without rebooting VMS (tried in the emulator):

$ IPNCP NAMRES EXIT 1          ! stop the name resolver first (otherwise it crashes)
$ IPNCP NETEXIT                ! then wait for "IPACP: Network offline" (≈ 10 s)
$ @SYS$MANAGER:IP_STARTUP      ! "IPACP: Net device 0 is XQA0:, IP=... (Online)"
$ IPNCP STARTUP /NAMRES        ! if NAMRES did not restart (SHOW SYSTEM)
$ IPNCP PING 192.168.2.1 64 3  ! check the gateway
$ IPNCP PING GOOGLE.COM 64 3   ! check the DNS

You can also reboot VMS (@SYS$SYSTEM:SHUTDOWN, automatic reboot YES). To start over, run @SYS$UPDATE:VMSINSTAL CMUIP again from the kit.

In the emulator, these are the addresses for each network mode:
  • Virtual network (Network menu): VAX at 10.0.2.15, mask 255.255.255.0, gateway 10.0.2.2.
  • Local bridge (vax-bridge relay, or term --bridge): a free address on your network, e.g. 192.168.2.77, with your router as the gateway.
The PC running the bridge reaches the VAX with telnet localhost 2323.

In the emulator

  • Repository disks (OpenVMS 7.1 installed): accounts SYSTEM, SYSTEST and FIELD, password VAX_EMU_2026.
  • To change disks, power the VAX off, except when the Install TCP/IP button changes the CD itself.
  • Paste: toolbar button or Ctrl+Shift+V. Copy: select the text, then the Copy button.
  • Turbo (toolbar): the VAX runs as fast as the browser allows while it is working (OpenVMS boots in about 9 s) and keeps real time while it waits; the VMS clock gains a little (SET TIME=12-OCT-2026:18:30 to set it back).
  • Disks are kept in the browser, which may erase them if space runs low: keep a copy with the Download button of the Disks menu. Shut OpenVMS down (@SYS$SYSTEM:SHUTDOWN) before closing the tab.
